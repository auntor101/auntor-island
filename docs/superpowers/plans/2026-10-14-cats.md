# Cats Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Fill Auntor Island with up to a dozen cats of ten different breeds that idle and wander around, each named when you walk up to it.

**Architecture:** One animated cat model (Quaternius Animal Pack Vol.2, CC0; binary FBX with two clips, `Idle` and `Walking`, and three flat materials `Grey`, `White`, `Pink`) is loaded fail-soft, cloned per cat with `SkeletonUtils.clone`, and given a breed look by recolouring its materials and scaling it (Maine Coon larger, and so on). A small pure state machine moves each cat between idling and walking inside the walkable island. If the model or loaders are missing, no cats appear and nothing else changes.

**Tech Stack:** three.js r128 `FBXLoader` + `fflate` + `SkeletonUtils` (vendored from `node_modules/three/examples/js`), vanilla JS, Node `assert`.

**Honest limits:** the model has only two animations, so cats idle and walk; sitting, grooming, pouncing and napping need more clips. Breeds are colour and size variants of one body, not different head shapes (a Persian face or a sphynx body would need extra rigged models). Higgsfield is not used (the account has 0 credits).

## Global Constraints

- Keep three.js r128 and classic `<script>` files. No bundler, no new runtime dependencies (vendored loader files are copied unchanged from `node_modules/three/examples/js`).
- Everything optional fails soft: missing loader, missing file or a bad model means no cats and a fully working game. The headless test (no FBXLoader) must still pass.
- Performance: target 60 fps on a mid-range phone; the touch profile already sits at about 153k triangles and 113 draw calls with no headroom, so cats must stay small: at most 6 cats on touch and 12 on desktop, mixers updated only for cats within 30 units of the camera, no real-time shadows or new lights.
- Look rules: toon materials only (`MeshToonMaterial` with the shared `GRAD` ramp, `skinning: true` for skinned meshes in r128); colours stay below about 0.85 brightness (bloom threshold 0.9).
- Licences: record the cat model in `assets/CREDITS.md`.
- `window.__lumen` debug hook stays. `npm test` must pass after every task.

- [ ] **Step 2: Implement the pure part**

Replace `js/cats.js` with:

```js
// Cats: ten breed looks of one animated model, wandering the island. Fails soft: without the model there are simply no cats.
(function (root) {
  'use strict';
  const BREEDS = [
    { name: 'Tabby', body: '#b98550', accent: '#f2e6d3', scale: 1 },
    { name: 'Black Cat', body: '#34303a', accent: '#34303a', scale: 1 },
    { name: 'Russian Blue', body: '#8d9bb0', accent: '#a9b6c8', scale: 1 },
    { name: 'Siamese', body: '#ecdcc3', accent: '#6a4b3c', scale: 1 },
    { name: 'Ginger', body: '#e08a3c', accent: '#f6d9b0', scale: 1 },
    { name: 'Calico', body: '#f4eee6', accent: '#d9833a', scale: 1 },
    { name: 'Tuxedo', body: '#312e39', accent: '#f4f1ec', scale: 1 },
    { name: 'Maine Coon', body: '#9a7a58', accent: '#d8c4a0', scale: 1.25 },
    { name: 'Persian', body: '#f1ebe0', accent: '#e4d9c6', scale: 1.1 },
    { name: 'Bengal', body: '#d3a04a', accent: '#f0dcae', scale: 1.05 },
  ];
  const SPEED = 0.9;

  function makeState(x, z, rand) {
    return { x, z, heading: 0, tx: x, tz: z, mode: 'idle', timer: 1 + rand() * 4 };
  }

  function pickTarget(c, rand, ok) {
    for (let i = 0; i < 8; i++) {
      const a = rand() * Math.PI * 2, d = 2 + rand() * 5;
      const x = c.x + Math.cos(a) * d, z = c.z + Math.sin(a) * d;
      if (ok(x, z)) { c.tx = x; c.tz = z; return true; }
    }
    return false;
  }

  function stepCat(c, dt, rand, ok) {
    if (c.mode === 'idle') {
      c.timer -= dt;
      if (c.timer <= 0) {
        if (pickTarget(c, rand, ok)) c.mode = 'walk';
        else c.timer = 2 + rand() * 4;
      }
      return;
    }
    const dx = c.tx - c.x, dz = c.tz - c.z, d = Math.hypot(dx, dz);
    if (d < 0.2) { c.mode = 'idle'; c.timer = 2 + rand() * 5; return; }
    const step = Math.min(d, SPEED * dt), nx = c.x + dx / d * step, nz = c.z + dz / d * step;
    if (!ok(nx, nz)) { c.mode = 'idle'; c.timer = 1 + rand() * 3; return; }
    c.heading = Math.atan2(dx, dz);
    c.x = nx; c.z = nz;
  }

  const api = { BREEDS, makeState, stepCat };
  const LI = root.LI = root.LI || {};
  LI.cats = Object.assign(LI.cats || {}, api);
  if (typeof module !== 'undefined' && module.exports) module.exports = api;
})(typeof window !== 'undefined' ? window : globalThis);
```

- [ ] **Step 2: Implement `spawn` and `update`**

In `js/cats.js`, inside the IIFE just before `const api = ...`, add the runtime part, and change the `api` object to include `spawn, update`:

```js
  // ---- runtime (needs THREE; only runs in the browser) ----
  const live = [];                     // {state, obj, mixer, idle, walk, breed, met}
  const FACE = 0;                      // radians added to heading; set in Step 4 after looking at the model
  const BODY_LEN = 0.55;               // world length of a scale-1 cat
  const NEAR_NOTE = 2.5, ACTIVE_DIST = 30;

  function coat(obj, breed) {
    const GRAD = root.LI.gfx.GRAD;
    obj.traverse(o => {
      if (!o.isMesh) return;
      const mats = Array.isArray(o.material) ? o.material : [o.material];
      const out = mats.map(m => {
        const n = (m.name || '').toLowerCase();
        const color = n.includes('white') ? breed.accent : n.includes('pink') ? '#e9a3a8' : breed.body;
        return new THREE.MeshToonMaterial({ color, gradientMap: GRAD, skinning: !!o.isSkinnedMesh });
      });
      o.material = Array.isArray(o.material) ? out : out[0];
      o.frustumCulled = false;
    });
  }

  async function spawn(o) {
    const A = root.LI.assets;
    try {
      if (!A || !A.fbx || !root.LI.gfx) return 0;
      const src = await A.fbx('animals', 'Cat');
      if (!src || !THREE.SkeletonUtils) return 0;
      const clip = n => src.animations.find(a => a.name.toLowerCase().includes(n));
      const idle = clip('idle'), walk = clip('walk');
      if (!idle || !walk) return 0;
      const box = new THREE.Box3().setFromObject(src);
      const size = box.getSize(new THREE.Vector3());
      const k = BODY_LEN / Math.max(size.x, size.z, 0.0001);
      const rand = root.LI.gfx.rand;
      const group = new THREE.Group();
      const made = [];
      for (let i = 0; i < o.count; i++) {
        const breed = BREEDS[i % BREEDS.length];
        let x = 0, z = 0, tries = 0;
        do { const a = rand() * Math.PI * 2, d = 3 + rand() * 12; x = o.near[0] + Math.cos(a) * d; z = o.near[1] + Math.sin(a) * d; tries++; } while (!o.ok(x, z) && tries < 40);
        if (!o.ok(x, z)) continue;
        const obj = THREE.SkeletonUtils.clone(src);
        coat(obj, breed);
        const holder = new THREE.Group();
        obj.scale.setScalar(k * breed.scale);
        holder.add(obj);
        const mixer = new THREE.AnimationMixer(obj);
        const aIdle = mixer.clipAction(idle), aWalk = mixer.clipAction(walk);
        aIdle.play(); aWalk.play(); aWalk.weight = 0;
        made.push({ state: makeState(x, z, rand), holder, obj, mixer, aIdle, aWalk, breed, met: false });
        group.add(holder);
      }
      if (!made.length) return 0;
      o.scene.add(group);
      made.forEach(c => { live.push(c); c.o = o; c.holder.position.set(c.state.x, o.h(c.state.x, c.state.z), c.state.z); });
      return made.length;
    } catch (e) {
      console.warn('cats failed:', e && e.message);
      return 0;
    }
  }

  function update(dt, cam, player) {
    if (!live.length) return;
    const g = root.LI.gfx;
    for (const c of live) {
      const o = c.o, s = c.state;
      const near = Math.hypot(c.holder.position.x - cam.x, c.holder.position.z - cam.z) < ACTIVE_DIST;
      if (near) {
        stepCat(s, dt, g.rand, o.ok);
        const target = s.mode === 'walk' ? 1 : 0;
        c.aWalk.weight += (target - c.aWalk.weight) * Math.min(1, dt * 6);
        c.aIdle.weight = 1 - c.aWalk.weight;
        c.mixer.update(dt);
        c.holder.position.set(s.x, o.h(s.x, s.z), s.z);
        c.holder.rotation.y += (s.heading + FACE - c.holder.rotation.y) * Math.min(1, dt * 8);
      }
      if (!c.met && Math.hypot(s.x - player.x, s.z - player.z) < NEAR_NOTE) { c.met = true; g.note('A ' + c.breed.name + '!'); }
    }
  }
```

and: `const api = { BREEDS, makeState, stepCat, spawn, update };`.

Note: the `heading` blend above can spin the long way around at the ±π seam; wrap the difference into [-π, π] before blending (`let d = s.heading + FACE - c.holder.rotation.y; d = Math.atan2(Math.sin(d), Math.cos(d)); c.holder.rotation.y += d * Math.min(1, dt * 8);`) and use that instead of the one-line version.
